Frequently Asked Questions

How private is InstantFlow compared to other tools?

Unlike other tools that route your transcripts through centralized background servers, InstantFlow runs stand-alone. All transcripts pass directly from your local machine to your chosen API provider (Groq/DeepSeek) using your personal keys. Your voice data never hits NovaFlow Labs' servers.

Do I need to prepare my own API keys for InstantFlow?

Yes, this is the core design for achieving "absolute local privacy." To protect your privacy, you must use your own API keys. InstantFlow enforces a strict dual Groq keys isolation policy for reliable transcribing and fallback polishing. The advanced DeepSeek polishing key is optional.
